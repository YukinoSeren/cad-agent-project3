# CAD Agent 组会摘要

开发时可从一次请求的调用链、实验复现和错误反馈读起。[CAD Agent 开发者读本](developer-guide.md)

**2026-11-25｜四人，约 30 天。** 组会可以先看一个反例，再讨论交互与实现范围。

| 已有证据 | 对课程作业的意义 |
|---|---|
| **本地实测**。SCA 2.3.0.post1 将 80 × 50 × 8 mm 板的通孔从 Ø10 改到 Ø14，STEP 回读确认孔心仍距左、下边 20、15 mm。故意将孔右移 5 mm 后，模型仍有效，体积也与正确版本一致，但超出 ±0.01 mm 容差。 | 给 Agent 的反馈可以具体到“孔心距左边实测 25，要求 20 mm”。验收器还要复测未修改的约束。[前后视图、脚本与复现](experiment/README.md) |
| **源码核实**。CADDesigner 将需求交给主 Agent，调用生成工具、执行建模脚本，并用视图检查。下一轮取回对话和状态摘要。三次视觉修复上限写在提示词里。它锁定 SCA 2.0.8。 | 可借鉴反馈如何返回模型；需自行实现尺寸验收、程序计数和版本留存。迁移到当前 SCA 的兼容性待测。[调用链与源码](02-source.md) |
| **公开案例**。CAD-Assistant 用标注视图辅助识别，Zoo 演示点选面后局部修改。工程案例把交互轨迹与最终环境结果分别评分。 | CLI 可用特征名和基准澄清“这个孔”，图形界面可提供点选。两种交互都能用“改对哪个孔、保留哪些尺寸”来评估。[产品比较](01-products.md) · [工程案例](04-engineering.md) |

**组会要决定的三个取舍**

1. 首版演示承诺哪些结构与修改？可用带孔板、阶梯轴、L 形支架检验覆盖面，再决定是否投入图形点选或更复杂的特征。[三例验收样表](03-simplecadapi.md)
2. 让模型生成 SCA 程序，还是让它组合有限的建模工具？拿同一个孔位反例比较表达能力、错误是否可定位，以及受限执行的成本。
3. 当外观合理但尺寸超差，谁有权放行？用同会话改参、运行异常、有效错件三条轨迹，讨论修复预算、超限时保留的证据及演示顺序。

**待验证。** 本轮跑通了几何实验；CADDesigner 按固定源码追踪，商业产品按公开资料核对。下一轮最能影响选型的证据，是用真实模型从模糊需求走到用户确认，连续修正错误并保留旧约束，以及确认超时后能终止整个受限执行进程。[SCA 能力与作业逐项对照](03-simplecadapi.md)
