# CAD Agent 系统设计

2026-11-27。四人团队，30 个自然日。v6，在 v5 验收契约上补充通孔净空、圆角全宽覆盖、并发发布和超时清理；可选 T4 补充插头净空。团队范围及人时决定不变。

## 意图

做一个课程作业要求的 CAD 建模智能体：用户用自然语言（可附图片）提出建模需求，系统先澄清缺失或冲突的关键条件，再由大模型规划并通过工具调用驱动 SimpleCADAPI 建模，程序独立测量实体、按容差判定，失败时把结构化反馈交回模型修正，同一会话内支持改参并保留未修改的约束，最终交付可查看、可改参、可导出的模型。

流程可信是基础要求，可以用澄清记录、超差拒收、重试终止和改参复测证明。模型复杂度也是课程评价的一项。底线用包含布尔、圆角和双截面验收的 T3 覆盖多特征建模，T4 手机支架保留为可选第四组，用实测结果和特征记录说明复杂度。 [课程要求](../../../README-zh.md#进阶任务)

## 目标

- 端到端跑通：自然语言 → 澄清 → 建模 → 测量验收 → 修正 → 交付
- 关键尺寸参数化，改参可重建，未修改的约束每次重测
- 两类失败（执行异常 / 几何超差）分别处理并各自计数，有重试上限
- 交付物齐全：参数化源文件、STEP、前后视图、对话与工具调用日志
- **交付的源文件在新进程中仅凭它本身 + 参数即可重建、改参、导出**（[偏置孔板 notebook 已实测](../../research/experiment/notebook/README.md)）

## 非目标

- 不训练模型，不自研几何内核，不实现复杂装配
- 不自研三维渲染器（作业明确不要求，复用 SCA 编辑器）
- 不做图形点选特征（"点选面再圆角"）
- 不做视觉检查回路（渲染→VLM 判断→返工），只做视觉**输入**

## 反目标

- 模型自行补全缺失尺寸后直接交付，用户没机会确认
- 只以"程序没报错"判定成功
- **已确认但无法测量的约束被当成通过**
- 改一个参数后，其他已确认尺寸悄悄变了却没人发现
- 演示时依赖未验证的集成环节

## 方案取舍

| 方案 | 做法 | 评估 |
|---|---|---|
| A 生成 SCA 脚本 | 模型写整段 Python，受限子进程执行 | 天花板最高，但报错是 traceback、修复要重写整段、执行隔离成本最高、演示波动最大 |
| **B 参数化工具调用（选定）** | 把 SCA 操作封装成带类型 schema 的工具，模型选工具填参数 | 错误定位到"哪个工具哪个参数"；参数即数据，天然支持改参与复测；工具封装本身即作业要求自主实现的部分 |
| C B 为主 + A 逃生 | 工具不够时模型写代码补 | 继承 A 的全部风险，还要模型判断走哪条，预算内是纯负担 |

作业允许工具调用或生成程序驱动 SCA。Zoo 的公开资料提供了类型化接口的产品案例，SCA 的 `sca ops` 实测列出 200 个带类型标注的操作。结合单零件范围，我们判断可用有限工具覆盖基线任务。工具集的覆盖与模型调用稳定性仍由首轮联调验证。

### SCA 原生能力与自主实现边界

实测确认 SCA 2.3.0.post1 已提供以下基础设施，**不自研**：

| 能力 | SCA 原生设施 |
|---|---|
| 符号参数 + 容差 | `scad.var(name, default, unit=, tolerance=, min=, max=, step=, label=)` |
| 派生表达式 | `Expr` / `ExpressionGraph` |
| 容差传播 | `ToleranceGraph` |
| 特征图记录 | `GraphSession` → `OperationGraph` |
| 图序列化与重放 | `export_graph_json` / `import_graph_json` / `replay_graph` |
| 会话导出 | `export_session_json`（含表达式图） |
| 几何查询 | `ql.faces()/edges()/solids().where(谓词).exactly(n)` |
| 实体检查 | `inspect_step_rbrepinspection` 等 |
| notebook 运行与改参 | `run_notebook(path, overrides=...)` |

**自主实现边界：**

- **工具封装**：包装成带 schema、供模型调用的工具 —— 自主
- **流程控制**：状态机、澄清、约束集、修复预算、版本管理 —— 自主
- **结果校验**：用 `ql` 选面/边、用 `inspect_*` 取几何事实、**自己写验收判据与容差比较** —— 自主

测量原语、OpenCASCADE 几何内核和执行能力由 SCA 提供。参考以下随 SCA 2.3.0.post1 发布的 Skill 规程，确认状态、工具封装、数值判定和流程控制由团队实现。

### 参数化源文件：图与 notebook 的职责分离

这是审计指出的关键缺口，已实测厘清。

| 产物 | 职责 | 改参能力 |
|---|---|---|
| `OperationGraph`（`export_graph_json`） | **精确重建**已保存的几何 | **无**。`replay_graph(graph, *, strict=True)` 不接受参数覆盖 |
| marimo notebook（`scad.var`） | **参数修改面** + 可查看交付物 | **有**。`run_notebook(path, overrides={...})` |

**改参不是"覆盖 Var 再重放图"，而是"覆盖 Var 重跑 notebook"。** 图里存的是字面值和表达式引用，表达式图另存于 session，所以图只保证原样重建。

**正式源文件是候选 STEP 的唯一建模入口。** 结构和工具 schema 校验通过的候选计划保留关键尺寸的参数 ID 与工具实参绑定，程序据此确定性生成 notebook 或降级脚本及参数 JSON，不从已展开为字面值的 `OperationGraph` 反推。工作进程用本轮确认参数运行这份源文件，导出供 `VERIFY` 回读的 STEP。规划阶段的试算产物不参与发布。通过验收后，将实际运行的源文件、参数与它导出的 STEP 作为同一版本交付；任一缺失或不是本次产物则不发布。

**生成器硬规则（实测）：** `run_notebook` 拒绝覆盖与其它参数同 cell 的 Var——

```
ValueError: the cell defining hole_d also defines hole_x, hole_y, length, thickness, width;
override them together, or define them in cells of their own
```

因此**每个参数必须独立成一个 cell**。这是能否单独改参的前提，写进生成器规格。

### 运行时验收：两份契约

审计指出的核心缺口。此前设计把"P4 规格离线"和"必须全部通过才能交付"放在一起，中间缺了一环。

**契约一：在线验收（运行时，从用户确认的约束出发）**

用户确认的内容按**结构化约束**记录。`measurement` 由固定 `id` 和类型化参数 `args` 组成，运行时按 `id` 调用测量函数。目标值、单位和容差单独保存。以 T1 的左边距为例：

```json
{
  "id": "hole_x",
  "statement": "孔心距左板边 20 mm",
  "unit": "mm",
  "criterion": {"mode": "within", "value": 20.0, "tolerance": 0.01},
  "source": "user_confirmed",
  "measurement": {
    "id": "axis_plane_distance",
    "args": {
      "target": {
        "kind": "face", "expected_count": 1,
        "where": {
          "geometry": "CYLINDER",
          "direction": {"kind": "axis", "vector": [0, 0, 1], "max_angle_deg": 0.1}
        }
      },
      "datum": {
        "kind": "face", "expected_count": 1,
        "where": {
          "geometry": "PLANE",
          "direction": {"kind": "normal", "vector": [1, 0, 0], "max_angle_deg": 0.1},
          "at_extreme": {"axis": "x", "side": "min", "within_mm": 0.05}
        }
      }
    }
  }
}
```

T1 现有样件只有一个竖直圆柱孔壁。这个选择器在孔位错到 25 mm 时仍定位到孔壁，让校验返回 `+5 mm`。多个圆柱面时须在确认阶段加入能区分特征的范围或关联关系，再执行测量。

<a id="measurement-contract"></a>

#### 测量接口（P1 ↔ P4）

每轮固定一个零件坐标系，记录原点和三个正交单位轴。下表中的位置、方向和截面以该坐标系表达，执行前转换至模型坐标。`section` 含 `origin` 和非零 `normal`，`probe` 含截面内的 `point` 与沿截面的非零 `direction`。`unit` 取 `mm`、`deg` 或 `bool`。选择器使用下节的结构。编号、字段、量纲和几何前置条件在联调前共同确认。未知编号、自由公式、参数类型或量纲不符均返回 `unsupported_measurement`，并说明原因。

**参数绑定。** 可绑定的标量位置支持字面值、`{"param": "t3.width"}` 或 `{"derived": "t3.width_midpoint"}`。后者引用由程序注册的派生函数及其依赖，例如按本轮确认的宽度除以二。所有引用在每次尝试前以**本轮冻结的确认快照**重新解析，包括测量 `args`、选择器窗口和验收目标。缺失、循环依赖或单位错误在执行前报告。日志保存参数快照 ID、解析后的实参和目标。修复沿用原快照，用户确认改参后建立新快照。

| `measurement.id` | `args` | 结果与前置条件 |
|---|---|---|
| `axis_plane_distance` | `target` 圆柱面、`datum` 平面 | mm。测轴线到平面的垂距，要求该轴线与平面平行。 |
| `diameter` / `radius` | `target` 圆柱面或圆边 | mm。由实际解析几何取值，圆柱面与圆边均可逐项测量。 |
| `plane_spacing` | `target` 平面、`datum` 平面 | mm。测两个平行支撑平面的垂距。 |
| `axis_angle` | `target`、`datum` 圆柱面 | deg。取两轴无向夹角 `acos(abs(dot))`，范围 0–90°。 |
| `axis_offset_at_section` | `target`、`datum` 圆柱面、`section` | mm。测两条轴线在同一指定截面上的交点间距，与 `axis_angle` 共同验收同轴关系。任一轴不与截面唯一相交则失败。 |
| `plane_normal_angle` | `target`、`datum` 平面 | deg。取两平面法向无向夹角 `acos(abs(dot))`，用于只关心两面偏离平行的量。 |
| `directed_section_angle` | `target`、`datum` 平面、`section`、`datum_toward`、`target_toward` | deg。将两个平面分别与指定截面求交得两条线，朝各自参考方向定向后取 0–180° 夹角。交线不唯一或无法确定朝向时失败。用于区分支撑面向前或向后倾斜。 |
| `dihedral_angle` | `target`、`datum` 平面、`into_target`、`into_datum` 两个方向向量 | deg。用实际支撑平面求交线，将两个指向各自臂内的参考方向投影到对应平面并去除交线方向分量，取两条有向射线夹角 0–180°。平行面或退化方向则失败。 |
| `edge_angle` | `target`、`datum` 直线边 | deg。用两条边的端点确定方向，取无向夹角 0–90°。 |
| `projected_span` | `target`、`direction`，或显式组合轮廓的 `targets`（选择器数组）和 `direction` | mm。测选中实体或有界平面外轮廓的投影跨度。首版平面外轮廓仅支持直线边，用端点求投影极值。组合模式取所选轮廓的共同投影范围。圆柱面轴向跨度用两个完整圆形边界圆心的轴向间距。整体包围盒只用于明确要求整件外廓的约束。 |
| `section_wall_thickness` | `target`、`datum` 平面、`section`、`probe` | mm。对本轮候选 STEP 回读的实体求截面，选取由两平行壁面界定的唯一材料区间，返回沿壁法向的厚度。区间或边界无法对应到两壁时失败。 |
| `section_gap` | `target`、`datum` 平面、`section`、`probe` | mm。对本轮候选 STEP 回读的实体求截面，探测线须得到由两侧壁限定、两侧都邻接材料的唯一空区间。返回沿探测线的宽度。 |
| `through_hole` | `target` 圆柱孔壁、`entry`、`exit` 平面、`min_clear_diameter`（mm） | 布尔。检查孔轴方向及两个圆形开口分别落在指定两面，开口实际邻接孔壁。再沿实测孔轴构造指定直径的净空圆柱，从入口延伸到出口，验证整段无材料遮挡。 |
| `fillet_full_width` | `target` 圆柱圆角面、`walls` 两个内侧平面、`ends` 两个宽度端面 | 布尔。首版仅支持 T3 的直边等截面圆角。检查该面与两内壁相接的两条纵向边界各自连续贯穿两端；两端分别由落在对应端面上的圆弧封边。不得有额外裁剪边界（不计同一边界上的分段）。半径另测。 |
| `insertion_clearance` | `size_mm`（长宽高及所需余量合计后的外包络尺寸）、`pose`（插接终点的中心与正交轴）、`travel_mm`（沿插头长度轴直线插入的行程） | 布尔。仅支持固定朝向的长方体包络。取从起始位姿到确认插接位姿的完整扫掠体，验证整个行程无材料遮挡。 |

**净空判定。** 对本轮候选 STEP 回读的实体与净空探测体做 BRep 布尔求交。只有求交成功且可判定无正体积材料交叠时通过，边界接触不算遮挡；求交失败或结果在数值精度内无法判定时拒收，不把异常当成空交。记录探测体实参、几何内核容差、交叠结果和失败原因。探测体只用于测量，不进入交付 STEP。不得以单条探测线或两端截面替代全段检查。

数值角规约先归一化向量，并把浮点内积限制到 `[-1, 1]`。判定类型为 `within`（`abs(实测−目标) ≤ tolerance`）、`at_most`（`实测 ≤ value`）或 `is_true`（布尔）。同一测量返回多个值时逐项判定，保留各实体的测量与失败记录。

截面计算使用 SCA 的 BRep STEP 检查接口，并保存 STEP 路径、截面与探测线以及两侧交点。[直边支架截面实测](../../research/experiment/README.md#step-截面探测验证)使用 `inspect_section_rdescriptor(step_path, origin, normal)` 验证了 STEP 回读和两处 4 mm 壁厚，也核对了探测线随宽度更新。边界关联和材料/空区的通用判定由验收层实现。

#### 选择器与命中数

选择器固定为 `{"kind": "face|edge|solid", "expected_count": n, "where": {...}}`，`n` 为正整数。`where` 内字段全部取交集，语义如下。

| 字段 | 类型与解释 | 原生实体与 STEP 回读实现 |
|---|---|---|
| `geometry` | 面 `PLANE` / `CYLINDER`，边 `LINE` / `CIRCLE`，实体不使用该字段 | 原生用 `ql.prop("geom.type", "==", ...)`。STEP 使用 BRep 报告的几何类型，统一为大写。 |
| `tag` | 原生实体的精确角色名，不含通配符 | 原生用 `ql.tag(...)`。STEP 验收计划须显式声明几何选择器。 |
| `center_window_mm` | 一个或多个轴的闭区间，例如 `{"x": [10, 30], "z": [0, 8]}` | 原生用 QL 的几何中心，坐标系一致时可用 `geom.center.*` 的下界和上界。STEP 用回读报告的 `midpoint`。各来源的窗口独立声明。 |
| `axis_window_mm` | 只用于圆柱面，含 `section` 和 `ranges`（按轴给出的坐标闭区间） | 用实际圆柱轴与截面的唯一交点筛选。这让相同孔径的多个孔也可以按轴的位置区分。 |
| `direction` | `{"kind":"normal|axis|tangent", "vector":[x,y,z], "max_angle_deg":a}`。平面用法向、圆柱面用轴、直线边用切向，按无向夹角筛选 | 在与模型轴对齐的平面法向场景可用 `geom.normal.*`。其它方向从几何数据计算；圆柱轴线读取 BRep `surface.axis`。 |
| `at_extreme` | `{"axis":"x|y|z", "side":"min|max", "within_mm":e}`。对垂直于指定轴的平面，将其位置与当前形体该轴外廓极值比较 | 用实测平面和外廓计算，适合 T1 左、下基准。目标是局部面时用已声明的局部位置或邻接关系。 |
| `adjacent_to` | 若干已完整声明的面选择器。候选边须同时属于指定面，候选面须与每个指定面共享边 | 原生的边选择可用 `shared_boundary`。STEP 用回读后的面边关联比较，仅在本次产物内使用关系编号。 |

原生条件能完整映射到 QL 时，使用 `ql.faces()`、`ql.edges()` 或 `ql.solids()`，组合谓词后调用 `.exactly(n).resolve(shape)`。若需用 BRep 数据完成剩余筛选，对**所有条件都满足**的最终集合执行同一 `count == n` 门禁。`expected_count` 由特征意图和已确认约束声明，重试与改参沿用。0、过少、过多均返回 `selection_mismatch`，附预期数、实际数、命中实体摘要和选择器。批量测量可声明 `n > 1`，保留每个结果。对于多个相同孔，用不同的基准窗口或邻接条件分别定位；窗口应宽到可测出该特征的位置超差，并窄到能与邻近特征区分。

**圆角/倒角的前置证据。** 执行前记录并打印 selection card，包含选择器、预期/实际命中数，以及每条边的长度和中心。涉及面时记录每个面的中心和面积。确认命中数后，按选定视角留存高亮图。SCA `2.3.0.post1` 的 `highlight_tags` 可解析相邻面的角色标签，精确高亮边使用 `highlight_edges` 传入同一批已解析的边。将两者传给同一次预览渲染，圆角继续使用同一批边。

交付前程序执行三项检查：

1. **覆盖**：本轮每条生效的几何约束均须有合法测量，包含 `user_confirmed`、`user_delegated` 和已纳入验收的派生量。无法表达的关键约束在确认前报告。执行后无法测量时记录 `unsupported_measurement` 或测量失败并拒收。
2. **解析**：按各选择器明确声明的 `expected_count` 解析，测量前置条件不满足也记录失败。
3. **判定**：每次布尔后检查体积为正、BRep 有效与壳闭合，分别记录。需要 BRep 检查时在 `GraphSession` 外调用诊断接口。交付前再次从本候选 STEP 检查有效性、闭合、正体积及预期实体数，然后逐项进行数值或布尔判定。报告保留约束 ID、目标、实测、带符号偏差、容差、判定及选择证据。

**契约二：离线评测（P4，独立判分）**

P4 的测试规格用于判断"系统有没有遗漏原始需求"——这是在线验收查不出来的，因为在线只验证"已确认的都做到了"，不验证"该问的都问了"。两份契约互不读取。

**Agent 在运行时不读 P4 规格。** 领域知识（板有长宽厚）写在提示词和工具描述里；P4 不向 Agent 注入离线答案。用户确认的值和在线验收反馈照常传给 Agent。

### 状态机与版本管理

```
INTAKE → CLARIFY（有缺项或冲突）→ CONFIRM → BUILD → CANDIDATE → VERIFY
   └──────────── 条件齐备 ──────────↑         │                       │
                                      执行异常/超时                 通过 → ACCEPT → DELIVER
                                              ↓                       │           新要求 → INTAKE
                                           REPAIR ←───── 验收失败 ───┘
                                              ├─ 预算允许，计入修复次数 → BUILD
                                              ├─ 需改已确认需求 → CLARIFY
                                              └─ 预算耗尽或同因连败 → FAILED
```

验收通过后仍须过发布门禁；基线过期则从 `VERIFY` 转 `FAILED`，不进入 `REPAIR`。

**版本规则：**

- 每轮生成独立**候选版本**，写到独立目录 `runs/<run-id>/attempt-<n>/`
- **只有源文件、实际运行参数及由其导出的 STEP 齐全，且 STEP 通过验收的候选才有资格发布**；失败时当前版本不变，上一版始终可取回
- **发布时核对基线。** 每轮确认快照记录开始改参所用的已验收版本 ID（首次建模为空），所有修复沿用。`VERIFY → ACCEPT` 在同一原子操作内比较该 ID 与会话当前版本 ID，仅匹配时更新当前版本。否则本轮以 `stale_baseline` 转 `FAILED`，记录基线和实际当前版本 ID；候选保留但不发布，不作为几何失败自动重试。若继续修改，从最新已验收版本重新进入 `INTAKE`，回显待合并和保留的约束，经用户确认后再建模
- 修复**只能改建模方案**（换工具、换顺序、换参数化写法）；冻结的确认快照、容差和验收规则不随修复修改。若需要改动已确认的约束，**必须回到 CLARIFY 重新询问**，不得静默改动

**确认规则：**

| 类别 | 处理 |
|---|---|
| **必须确认** | 影响外部几何的尺寸、单位、定位基准、空间关系 |
| **可代决** | 用户明确说"你决定"时，记录 `user_delegated` + 授权时间 + 取值依据 |
| **派生值** | `source: derived`，记录计算公式与所依赖的已确认参数；改上游自动重算，不单独确认 |
| **可建议** | Agent 提出的值（如 65°），标 `agent_proposed`，交付前须转 `user_confirmed` 或 `user_delegated` |

确认以结构化清单呈现（参数名 / 建议值 / 单位 / 基准），逐项确认或改写。自由文本答复由模型解析后**仍要回显成清单再确认一次**。

**需求覆盖门槛。** 在 `CONFIRM` 给本轮用户原话和澄清答复中的每条要求分配 ID，保留原文片段及轮次。确认清单逐项展示 ID、解释、对应约束 ID 及测量方式。仅涉及外观的非尺寸要求可映射到指定人工查看视图，明确由用户核对。缺项与冲突集中询问。无法满足的要求要显式标为待澄清、当前不支持或经用户同意延期。阻塞项未解决就保持确认状态并报告，延期要得到用户批准。离线评测另外对照原话，检查是否有整条需求在提取阶段被遗漏。

**改参按差量合并。** 同一会话以当前已验收版本的完整确认集为底稿，而不是从本轮短句重建约束集。只有用户明确确认的新增、修改或删除可写入新快照；其余需求、约束 ID、单位、基准、容差及测量定义原样继承，只重算受变更影响的派生值和测量实参。回显变更项及保留项，日志关联基线快照、新快照和变更清单。未通过的候选不改变下轮基线。

**重试与计数（H1 已确认）。** 单轮初次执行 1 次、修复最多 3 次，总执行最多 4 次。执行异常（含超时）最多触发 2 次修复，验收失败最多触发 2 次修复，两类分别记录，且共同受总次数限制。

- 执行每次候选时递增总次数，首次计入。修复次数在带着对应失败反馈进入下一次执行时递增。等待用户确认不消耗修复次数，重启工作进程不重置计数。
- 每次失败保存规范化 `cause_key`，由失败类型、工具或验收项 ID、特征与稳定错误码组成。超差用验收项和故障类别判因，同源问题不因消息措辞或浮点偏差改变而重置。
- 同一主因连续失败 2 次、该失败类型的修复额度用尽或总执行达到 4 次且仍失败时，转 `FAILED`。保存候选、错误与测量证据，说明未通过项并保留上一通过版本。预算与每次计数写入配置和日志。

**参数绑定不能替代复测。** 每轮逐项复测新快照中的全部生效约束，包括未改的尺寸和拓扑；不能只测本轮变更清单里的参数。

### 工作进程与恢复

- Windows 下每次尝试使用独立的 **Job Object**。父进程持有 Job 句柄，启用 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`，在工作进程仍处于挂起状态时将其加入 Job，再恢复运行，不允许子进程脱离 Job。加入失败时终止挂起的进程、报告执行异常，不恢复运行，也不降级为 `psutil` 枚举后逐个终止。
- 超时由父进程终止整个 Job，并确认活动进程数为 0 后才允许重试。无法确认清理完成则报告执行异常并停止自动重试，保留当前已验收版本。
- 每次尝试写独立输出目录；STEP 先写临时文件，**写完并可读后才原子重命名**。已超时的尝试不进入验收，即使它留下了已重命名的 STEP。
- 每次执行前落盘**本轮确认快照与候选建模计划**。终止后按本轮快照和失败记录重建，首次运行也可恢复。上一通过版本保留给用户，并用于新一轮改参的起点。

**联调用例。** 分别在首次建模和已有版本的改参中触发超时。测试工作进程先启动一个持续向本次目录写入的辅助进程，再等待超时。记录父子进程退出和 Job 活动进程数，确认辅助进程不再写入、超时产物不进入验收，随后从同一轮确认快照重跑。已有上一版时，验证旧版本可读且仍通过原判据。

**工具输入与输出边界。** 模型只提供类型化工具调用，不能提交 Python 源码；程序根据校验通过的计划确定性生成 notebook 或脚本。工具 schema 只接受逻辑产物名，例如 `step`、`before_view`，宿主按白名单映射到当前 `runs/<run-id>/attempt-<n>/` 内的文件。目录由宿主建立，解析后核验路径归属，拒绝目录跳转、绝对路径或指向目录外的链接。

**生成代码的运行限制。** 上述白名单与超时只约束工具接口和运行时长，不代表工作进程已隔离。首次联调前由 P1 确认 [课程对受限环境的要求](../../../README-zh.md#工具选择)，并记录实际采用的运行身份或隔离机制。建议用独立的低权限身份或隔离环境，只读访问依赖和输入，只写当前候选目录及其临时区，不传入模型 API 凭证。网络、内存限制按确认的口径实现并如实记录，不宣称未验证的隔离。notebook 和降级脚本适用同一边界；若 `sca edit` 会在这条边界之外执行生成代码，Web 改走 PNG + STEP。正式联调须验证越权写入测试文件被执行环境拒绝，并另测工具路径拒绝和超时终止；未确认或未通过时不得把正式链路标为满足受限执行。

## 测试任务与验收条件

单位 mm / 度。每个任务记录：验收条件、容差、成功情况、实测偏差、耗时、修复次数、失败原因。

### T1 偏置通孔板（基线回归）

- 初始："做一块 80×50×8 的板，左边开个通孔"——**故意缺孔位与孔径**
- 澄清：孔心距哪条边、距多少、孔径、单位
- 验收：单一有效实体，板长/宽/厚 80/50/8 mm（±0.01 mm），初始通孔直径 10 ±0.01 mm，孔心距左边 20 ±0.01 mm、距下边 15 ±0.01 mm。用 `through_hole` 检查两侧开口和全厚度净空；`min_clear_diameter` 由本轮确认孔径减去孔径容差得到，初始为 9.99 mm。
- **通孔反例**：保留两侧开口、圆柱孔壁和六项尺寸，在两开口之间添加与孔壁相连并伸入净空圆柱的挡片。要求开口和尺寸检查通过，但全段净空因检测到材料交叠而拒收。
- 修改：用户确认「孔径改成 14 mm」后，只更新孔径目标，由此将净空探测直径重算为 13.99 mm；其余约束 ID 和判据不变。重新验收板长/宽/厚、孔径、左/下孔心距六项尺寸，以及开口与全厚度净空、有效性、闭合、正体积和单一实体。
- **既有尺寸与开口基线**见 [SCA 实验](../../research/experiment/README.md)；全厚度净空的正反例另按本版判据联调。

### T2 阶梯轴（回转体、同轴度）

- 澄清：两段长度、两段直径、是否同轴
- 验收：大径 20 ±0.05 mm，小径 12 ±0.05 mm，从肩部至大径端面实测 30 ±0.05 mm，从肩部至小径端面实测 20 ±0.05 mm。两端总长是派生检查 50 ±0.10 mm。以大径端起点为零，设计交界截面绑定本轮确认的大径段长度，用 `axis_offset_at_section` 比较两轴交点（≤0.05 mm），并用 `axis_angle` 检查夹角（≤0.1°）。
- **修复用例 A（几何超差）**：首轮建模计划含错误实参，使实际小径为 14 mm。验收须拒绝并反馈 `实测 14 / 目标 12 / 偏差 +2`。真实 Agent 根据反馈修改计划后，按原快照复测并通过；同一错误计划若原样重跑必须仍被拒绝。
- **恢复用例 B（瞬态执行异常）**：首次调用圆柱工具注入一次非法半径，验证异常分类、反馈中的工具名和实参，以及异常解除后按原验收重跑。本用例不作为 Agent 改方案的证据。
- **独立源文件改参**：在新进程中把正式交付源的小径由 12 改到 13 mm，导出 STEP，按新小径目标及其余原判据复测。

### T3 L 形支架（多特征、圆角、夹角）

- 澄清两臂长度、宽度、壁厚、内夹角、需要圆角的位置和半径。基线夹具采用一条沿宽度方向的内角折线，圆角半径 2 mm，作为测试输入让用户确认。
- 零件坐标以外侧墙面 `x=0` 与底面 `z=0` 的交线为基准，`+X` 沿水平臂、`+Z` 沿竖直臂、`+Y` 沿宽度，起点为 `y=0`。**水平臂量 `z=0` 的底面**，平面法向平行 `Z`，用其外轮廓沿 `X` 投影。**竖直臂量 `x=0` 的外墙面**，平面法向平行 `X`，用其外轮廓沿 `Z` 投影。两处 selector 各预期 1 面，按对应零位窗口定位。两臂均验收外长 40 ±0.1 mm 和 `Y` 向宽 25 ±0.1 mm。确认有一个有效实体。
- **水平臂壁厚**用 `section_wall_thickness`，截面 `x=20 mm`，探测线经过 `(20, W/2, 0)` 沿 `+Z`。两壁为外底面和水平臂的内侧上平面，均按平面类型、接近 `Z` 的法向及各自的 `z` 位置段定位，每个预期 1 面。
- **竖直臂壁厚**同样测在截面 `z=20 mm`，探测线经过 `(0, W/2, 20)` 沿 `+X`。两壁为 `x=0` 外侧墙面和竖直臂的内侧平面，按相同规则沿 `x` 定位。`W` 是本轮确认的宽度。两臂的壁厚各为 4 ±0.1 mm，判据要求探针的材料区间确由对应两壁界定。
- **壁厚反例**：候选 STEP 保留两臂外长和宽度，只把水平臂厚度从 4 改为 5 mm。选择窗口仍须识别两壁，截面实测 5 mm，返回 `偏差 +1 mm` 并拒收；不得因选不中而跳过测量，也不得用外廓尺寸代替。
- **夹角**用两内侧平面做 `dihedral_angle`，水平面的臂内方向为 `+X`，竖直面的为 `+Z`，实测内夹角 90 ±0.5°。
- **圆角**从两个内侧平面的共同边界选择沿 `+Y` 的直线边，预期 1 条。圆角前打印选择卡，核对边中心是否在两内壁的交界、边长是否与当前宽度一致，按上述规则保存 `iso` 高亮图。交付时在 STEP 上找与两内侧平面都邻接、轴线平行 `Y` 的圆柱面，预期 1 面，实测半径 2 ±0.2 mm。选择条件使用类型、轴向和邻接，不以半径或覆盖范围筛选。再用 `fillet_full_width` 验证圆角连续覆盖两个宽度端面之间的全宽；端面按平行 `Y` 的法向及 `Y` 轴两侧外廓极值定位，各预期 1 面。
- **圆角反例**：只在支架宽度中段做半径 2 mm 的圆角，两端保留锐边。要求仍能定位圆角面并测得合格半径，但全宽覆盖判据拒收。
- 修改：用户说「宽度改成 30 mm」后，日志应显示两条探测线的 `Y` 坐标从 12.5 更新至 15 mm。重测宽度和其余全部既有约束，重新留存圆角选择证据，并在最终 STEP 上复测圆角是否覆盖新宽度。

```text
沿宽度方向看（剖面 XZ）
      +Z
       ↑  竖直臂
 x=0   │▐   ← z=20：沿 +X 测厚
 外墙  │▐          ↑ x=20：沿 +Z 测厚
       └▆▆▆▆▆▆▆▆▆→ +X（水平臂）
        z=0 底面
```

### T4 手机支架（图文联合输入、局部特征）——可选第四组

- 输入：手机（带壳）图片 + "做个放桌上看视频的支架"
- **图片的作用是定性与提供候选，不是测量。** 普通照片无比例尺，VLM 给的是**基于常见机型的建议值**，须用户确认
- 澄清时先描述图中设备或参考结构的整体形态、可见特征与相对位置、朝向，以及隐藏或不确定部分，提交给用户确认。再确认设备尺寸、支撑角度及倾斜朝向、横竖放、充电避让缺口。充电避让还须确认插头外包络的长宽高、所需余量、以放置后的手机充电口为基准的插接位姿，以及从外侧沿插头长度轴直线插入的方向和行程。图像描述和建议值逐项回显，确认完成后才建模。
- 验收坐标以底座下平面 `z=0` 为基准，`X` 为横向、`+Y` 从前向后、`+Z` 为上。尺寸目标及局部选择窗口所需参数绑定本轮确认快照，设备尺寸变化时重新解析。
  - **支撑角**用 `directed_section_angle`。在 `x` 为支架确认宽度一半的中截面求接触面和底座下平面的交线，底座交线朝 `+Y`，支撑面交线朝 `+Z`。按用户确认的倾角验收，容差 ±1.0°。试件取 65° 后倾，另做 115° 前倾反例，须明确拒收。接触面预期 1 面，用独立于目标倾角的位置窗口和邻接关系定位。
  - **底座与托唇的整体占地**沿 `Y`、`X` 测量，各 ±0.5 mm。`projected_span` 组合底座下平面的有界轮廓和托唇的水平足迹，取 XY 投影联合范围。底座下平面预期 1 面，法向平行 `Z`，中点 `z∈[-0.05, 0.05] mm`。T4 的托唇按竖直侧壁夹具，用缺口两侧的托唇顶面边界表示足迹，以唇区位置和邻接关系定位，预期命中数由确认的特征声明。斜撑面不纳入该占地测量。另用托唇外伸反例，要求实测占地跨度超过确认值及容差并拒收。
  - **托唇高度**：基线夹具的顶部开口将托唇顶面分为左右两片。用各自的局部位置窗口分别选 1 面，各自与同一底座下平面做 `plane_spacing`；两侧分别按确认高度及 ±0.5 mm 验收，不取单侧或平均值。
  - **缺口宽度和位置**先定位托唇两侧的缺口内壁，均为预期 1 面、法向平行 `X` 的平面，以夹具中分开的左、右位置窗口区分。在穿过托唇有效高度中点的水平截面上，沿 `X`、于唇前后边界中点处穿过缺口，用 `section_gap` 验证两壁间空区并测宽度。用 `plane_spacing` 从托唇左端面到左内壁测缺口位置，两项各 ±0.5 mm。反例保留两侧内壁的位置，在探测线经过处增加挡片中断空区；即便两内壁间距正确，仍须以空区不符合为由拒收。
  - **充电插头净空**另用 `insertion_clearance`，将确认的外包络及余量、插接位姿和直线行程绑定到本轮快照，在候选 STEP 上验证完整插入路径。另做一个避开中点探测线但侵入插头扫掠体的挡片反例；`section_gap` 和缺口位置应通过，插头净空须拒收。该判据只验证支架不挡插头，不验证插头与设备接口的配合或线缆弯折。
  - 单一有效实体。
- 交付一张指定视角的渲染图供人工对照已确认的外形。报告分别记载 VLM 的解读和建议值、用户确认，以及程序几何实测。

## 评审问题的处理

| 审计意见 | 处理 |
|---|---|
| 运行时验收缺"需求→判据"规则 | 结构化约束由测量编号、参数与量纲组成；校验本轮生效的约束。选择器限定几何、位置、方向、标签和邻接语义，按特征意图声明命中数；不可测则明确报告并拒收 |
| 参数化源文件改参路径缺证据 | 手写 T1 样件已验证；正式候选由实际交付源文件生成 STEP，T1–T3 须在新进程重建、单参改值并回读复测 |
| D5 降级只写"手工组装 notebook" | 改为**确定性生成的 Python 脚本 + 参数 JSON**，与 notebook 共用发布与受限执行门槛 |
| 确认/改参/修复缺统一状态规则 | 改参以已验收版本的完整确认集为底稿，只应用确认变更；修复不改冻结的快照和判据 |
| 并发改参可能覆盖较新的已验收版本 | 比较基线与更新当前版本在同一原子操作中完成；过期候选不发布，联调验证两个均通过验收的候选只有一个更新当前版 |
| 进程终止后恢复缺路径，`psutil` 枚举不能保证清理完整 | Windows 每次尝试在 Job Object 中启动，清空 Job 后才从本轮快照恢复；超时夹具包含仍在写入的辅助进程，保留上一通过版本；工具路径与运行限制仍分别验证 |
| T1 通孔只验证开口，未验证孔内净空 | 按本轮孔径下限对回读 STEP 做全厚度净空判定；保留正确开口但孔内有挡片时拒收 |
| 人时口径不一致 | 工作日容量 160–176 人时，基础估算 148 人时，缓冲 12–28 人时，T4 为可选第四组 |
| 测试未覆盖异常修复、重试耗尽、取回上一版 | 区分瞬态重跑与真实 Agent 改计划，要求保留反馈、计划差异和快照 ID；独立验两类预算、总预算及旧版取回 |
| T3 壁厚、夹角与圆角缺可执行判据 | 固定两个测厚截面与各自壁面，定义内二面角；圆角在最终 STEP 上验收半径及全宽覆盖，增加壁厚超差和局部圆角拒收轨迹 |
| T4 缺具体测量对象，单条探测线不能证明可插接 | 规定倾角、含托唇的占地及双侧高度；缺口另验完整插头扫掠净空，用避开探测线的挡片验证拒收；仍仅在启动 T4 时执行 |
| FastAPI 属 SCA 依赖 | **订正**：SCA `editor` extra 仅 starlette/uvicorn/websockets |
| `--replay` 含义混淆 | 拆为 `--rebuild`（重建几何）与 `--replay`（回放交互日志） |
| Web 可被放弃，缺基线界面 | **定为底线**：PNG + STEP 只替换三维查看；两条展示路径均须以 T3 宽度变更实测同尺度 |
